Summary

This website does not set cookies for visitors and does not use analytics, advertising or social-media tracking. No optional tracking is active. Because nothing optional is used, no cookie banner is shown. You can review this at any time using the panel.

Browser storage we use

The website uses a small amount of browser storage that is strictly necessary for features you use:

NameTypePurposeDuration
sd_enquiry_timessessionStorageCounts enquiry submissions in this tab to prevent repeated sendingDeleted when the tab is closed

Analytics

No analytics tool is currently installed. If analytics is added in future, it will:

  • be off by default and load only after you choose “Accept all” or switch it on under “Manage preferences”;
  • be listed on this page with each cookie’s name, purpose and duration;
  • be easy to switch off again at any time from “Cookie preferences”.

Third-party services

No third-party fonts, maps, videos, social-media widgets, chat tools or reCAPTCHA are embedded. “View location on map” links open Google Maps in a new tab only when you click them; Google’s cookies policy then applies on Google’s site.

Managing storage

You can delete cookies and site storage in your browser settings at any time. Blocking storage does not prevent you from browsing the website.
